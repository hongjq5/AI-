## 自行配置

按照 [项目首页](../README.md) 和 [运行说明](../local-runtime/README.md) 操作：

1. 复制 `local-runtime/.env.example` 为 `local-runtime/.env`，填写自行生成的服务凭据。
2. 复制 `local-runtime/ai.env.example` 为 `local-runtime/private/ai.env`；AI 默认禁用，启用前填写自己的凭据和模型并确认接口可用。
3. 安装依赖并启动后，通过注册页面创建自己的应用账号。源码不提供通用账号或密码。
4. 将新生成的日志、截图、配置与数据留在本地；检查 Git 待提交内容，确认只包含预期源码与文档。

`.gitignore` 只能约束后续未跟踪文件，不能删除已经提交过的秘密或撤销泄露。若曾将真实凭据提交或发送到公开位置，应到对应服务撤销并重建凭据；本次清理不自动修改外部服务。
